## Cara pasang atau kemas kini preview

1. Muat turun `KAMI-Rangkai.apk` pada telefon Android dan tunggu sehingga selesai.
2. Buka fail melalui notifikasi muat turun atau aplikasi **Files / Fail**.
3. Jika diminta Android, benarkan pemasangan daripada pelayar atau aplikasi Fail yang digunakan.
4. Semak nama **KAMI Rangkai**, kemudian sahkan **Pasang** atau **Kemas kini**. Buka app selepas pemasangan selesai.

Muat turun tidak memasang app secara automatik. Untuk kemas kini preview sedia ada, pasang terus di atas preview lama supaya data dan pilihan peribadi dikekalkan. Untuk app rasmi, gunakan Google Play; APK preview ini tidak menggantikannya.

**Jika terdapat ralat tandatangan atau kemas kini gagal, jangan uninstall atau padam data app.** Simpan mesej ralat dan hubungi pembangun untuk semakan.
